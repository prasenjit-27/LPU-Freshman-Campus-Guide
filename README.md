
# LPU Freshman Campus Guide

A student-friendly campus guide designed to help newcomers at **Lovely Professional University (LPU)** navigate university life, discover campus facilities, and get familiar with their new environment.

## About the Project

Starting university can be overwhelming for freshers. Finding facilities, understanding campus resources, and knowing where to go for essential services can take time.

The **LPU Freshman Campus Guide** aims to make this transition easier by providing useful campus information in one convenient place.

## Objectives

- Help freshers become familiar with the LPU campus.
- Make it easier to discover important campus facilities.
- Provide useful information for everyday university life.
- Improve the onboarding experience for new students.

## Planned Features

- **Campus Guide:** Information about important campus locations and facilities.
- **Facility Directory:** Quick access to essential student services.
- **Freshers' Resources:** Helpful information for newly admitted students.
- **Student-Friendly Interface:** Simple and accessible navigation.
- **Campus Information:** Useful details to help students settle into university life.
